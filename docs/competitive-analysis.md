# 海钓潮汐小程序竞品分析

## 1. 目标用户与场景

核心用户是中国沿海海钓爱好者，主要覆盖以下场景：

- 周末短途出钓，关注今天和明天是否值得去。
- 异地找钓点，担心不熟悉潮水、风浪和停车补给。
- 固定钓场复购，需要沉淀个人钓点、鱼种与出钓记录。
- 新手入门，希望通过简单建议理解“什么潮位、什么时段更适合钓什么鱼”。

用户真正要完成的任务不是“看懂潮汐表”，而是“降低空军概率，提升出钓把握”。

## 2. 竞品盘点

### 潮汐表精灵

来源：[App Store](https://apps.apple.com/cn/app/%E6%BD%AE%E6%B1%90%E8%A1%A8%E7%B2%BE%E7%81%B5/id1574589902)

已公开能力：

- 全国潮汐查询
- 风浪、天气、水温
- 钓鱼/赶海时间分析
- AI 识鱼

优点：

- 功能覆盖广，典型工具型产品。
- 直接服务钓鱼和赶海场景，用户理解门槛低。

短板：

- 更像通用潮汐工具，海钓决策链路不够深。
- 缺少围绕“钓点 + 鱼种 + 玩法”的结构化产品表达。

### 潮汐日历

来源：[官网](https://www.tides.net.cn/)

已公开能力：

- 全球潮汐预测
- 小时级海洋天气
- 海浪、洋流、深层洋流
- 内置 300+ 海钓和赶海地点

优点：

- 海洋环境数据维度非常全。
- 专业感强，适合重度户外玩家。

短板：

- 信息密度高，普通钓友上手门槛偏高。
- 数据强，但“今天怎么钓”这一步仍需用户自行判断。

### 钓鱼佬

来源：[官网](https://5cm.fun/) 、[App Store](https://apps.apple.com/ro/app/%E9%92%93%E9%B1%BC%E4%BD%AC/id6443960894)

已公开能力：

- 钓鱼指数预报
- 高清卫星地图
- 钓点数据
- 潮汐、气压、月相
- AI 识鱼

优点：

- 以“出钓全流程工具”组织体验，产品叙事完整。
- 有钓点和社区属性，天然具备增长土壤。

短板：

- 海钓只是其中一类场景，不一定能深挖沿海海钓差异化需求。
- 泛钓鱼产品容易在海钓专业性上不够聚焦。

### 通用潮汐类 App

来源：[Google Play 潮汐表](https://play.google.com/store/apps/details?id=com.maisidun.tide)

典型特点：

- 潮汐、满潮干潮、基础天气。
- 服务赶海、潜水、航海等多个场景。

短板：

- 通常缺少本地化钓点经营能力。
- 缺少面向海钓用户的“出钓建议”和“经验沉淀”。

## 3. 市场空档

现有产品大致分成两类：

- 数据工具型：潮汐、天气、风浪做得好，但留存靠刚需查询，关系偏弱。
- 泛钓鱼社区型：内容和钓点较强，但海钓专业决策没有做深。

对海钓玩家来说，真正有价值的产品应该把以下四件事串起来：

- 找到附近靠谱海钓点。
- 看懂未来 24 小时潮汐与海况。
- 给出具体玩法建议，例如“清晨 5:00-7:00 适合矶钓黑鲷”。
- 形成个人复盘与钓点资产。

这正是小程序最适合切入的窗口，因为小程序在“轻量高频查询 + 社交传播 + 本地服务转化”上天然更占优势。

## 4. 产品竞争策略

### 4.1 首要定位

不是做“又一个潮汐表”，而是做“海钓决策助手”。

首页应当优先回答：

- 今天值不值得去？
- 去哪个钓点更合适？
- 最佳窗口在几点？
- 需要注意什么风险？

### 4.2 差异化抓手

建议按以下顺序建立竞争力：

1. **钓点级决策**
   将展示单位从“城市/港口”升级为“具体钓点”，包括码头、防波堤、礁石区、滩涂口。

2. **玩法化建议**
   不只给数据，要给出海钓语言的建议：
   “中潮上半程适合路亚青物”“浪高偏大，不建议站礁”。

3. **本地经验沉淀**
   允许用户收藏钓点、记录渔获、沉淀个人最佳潮位和鱼情。

4. **轻社区而非重社区**
   先做钓点卡片、渔获战报、出钓点评，不一开始做重内容社区，避免冷启动压力。

5. **交易闭环**
   从导购和服务入手，而不是一开始就卖会员。比如：
   渔具店联营、船钓/向导预约、钓点周边停车补给、天气险和会员增值服务。

## 5. 建议的产品路线

### 阶段一：高频工具起盘

目标是让海钓用户愿意每天打开。

必须做好：

- 一键定位附近海钓点
- 今日/明日潮汐窗口
- 海钓指数
- 风浪风险提醒
- 收藏钓点与分享海报

### 阶段二：经验沉淀与轻社交

目标是提升留存与内容供给。

增加：

- 钓点点评
- 渔获记录
- 本周战报
- 同城钓友动态

### 阶段三：商业化放大

目标是在不伤害工具体验的前提下变现。

优先级建议：

1. 本地渔具店/船家/民宿/停车场商家入驻
2. 会员订阅，提供更长周期预测与高级海况
3. 渔具分销与内容种草
4. 赛事、活动和品牌合作

## 6. 商业化建议

### 适合优先验证的变现方式

- **会员订阅**
  提供 7/15 天高级海况、专业钓点包、风浪预警、私人出钓日历。

- **本地商家分发**
  在钓点详情页展示“附近渔具补给”“船钓拼船”“停车洗手间”等本地服务。

- **钓点包/城市包**
  对热门沿海城市提供精品钓点专题包，例如舟山、厦门、青岛、三亚。

- **品牌广告**
  只在强场景页做原生广告位，避免首页工具体验被破坏。

### 不建议首发就重押的方向

- 纯内容社区广告
- 复杂电商闭环
- 过早引入大量 UGC 审核成本

## 7. 结论

这类产品要赢，关键不在“潮汐数据更多”，而在“把海钓决策做得更省脑、更本地化、更可复盘”。  
首版最值得做的是：以钓点为中心，把潮汐、风浪、天气、玩法建议和本地服务整合成一个极简但可信的出钓助手。
